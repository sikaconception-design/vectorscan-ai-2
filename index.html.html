Indices entomologiques automatiques

Indice de récipients (CI) calculé sur toutes les fiches. Indice maison (IM) et indice de Breteau (IB) nécessitent le champ « N° de concession / maison » renseigné dans les fiches, ou une saisie manuelle du nombre de maisons visitées.

IB = gîtes positifs pour 100 maisons inspectées ; IM = % de maisons avec ≥1 gîte positif ; CI = % de gîtes positifs parmi les gîtes inspectés (OMS, 1971). Les seuils de risque affichés sont indicatifs et doivent être validés selon le vecteur et les recommandations sanitaires locales.
